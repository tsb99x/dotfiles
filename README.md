# Dotfiles

Collection of my dotfiles to share.

## NVIM

NVIM configs are specific to Debian Trixie, i.e. NVIM v0.10.
Some plugins support only v0.11+ now, so they are pinned to the last relevant versions.

## Fish

Most of the time, I use Fish shell.
It has good defaults out of the box, but I still wrote a couple of useful functions and aliases myself.
